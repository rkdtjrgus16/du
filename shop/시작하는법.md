# 내 쇼핑몰 시작하는 법

## 1단계: 패키지 설치
```
npm install
```

## 2단계: 환경변수 설정
1. `.env.local.example` 파일을 복사해서 `.env.local` 로 이름 바꾸기
2. 각 값 채우기:

### OpenAI API 키 (필수)
- https://platform.openai.com/api-keys 접속
- "Create new secret key" 클릭
- `OPENAI_API_KEY=sk-...` 부분에 붙여넣기

### Supabase 설정 (무료)
1. https://supabase.com 에서 계정 만들기
2. "New project" 클릭 → 프로젝트 이름, 비밀번호 설정
3. 프로젝트 생성 후 Settings > API 에서:
   - `NEXT_PUBLIC_SUPABASE_URL` = Project URL
   - `NEXT_PUBLIC_SUPABASE_ANON_KEY` = anon/public 키
   - `SUPABASE_SERVICE_ROLE_KEY` = service_role 키

4. SQL Editor에서 `supabase/schema.sql` 파일 내용 실행

### 관리자 비밀번호
- `ADMIN_PASSWORD=원하는비밀번호` 설정

## 3단계: 실행
```
npm run dev
```

브라우저에서 http://localhost:3000 접속!

## 주요 페이지
- `/` - 고객 쇼핑 메인 (상품 목록, AI 검색, 챗봇)
- `/admin` - 관리자 페이지 (상품 관리, 주문 확인)
- `/admin/products/new` - 상품 등록 (AI 설명 자동 생성)

## AI 기능 사용법
- **챗봇**: 쇼핑몰 오른쪽 아래 💬 버튼 클릭 → "빨간 원피스 추천해줘"
- **AI 설명 생성**: 상품 등록 페이지에서 상품명 입력 후 "✨ AI로 설명 생성" 클릭
- **AI 검색**: 검색창에 "따뜻한 겨울 선물" 같이 자연어로 검색
